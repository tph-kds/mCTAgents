# Security Review Example

## Overview

This example demonstrates using mCTAgents to perform a security review of a system design.

## Usage

```bash
cd examples/security-review
python main.py
```

## What It Does

1. Sends a security review problem to the reasoning engine
2. Streams events showing agent debate in real-time
3. Displays the final security assessment

## Problem

The example evaluates the security implications of a specific system architecture, producing structured claims about vulnerabilities, mitigations, and risk levels.
