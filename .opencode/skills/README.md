# Skills

This folder contains reusable skills and workflows for coding agents.

## Structure

```
skills/
├── README.md              # This file
├── schema-validation/     # Skills for working with protocol schemas
├── reasoning-workflow/    # Skills for implementing CCSR workflow
├── agent-development/     # Skills for building agents
└── deployment/            # Skills for Docker/deployment tasks
```

## Skill Format

Each skill should contain:
- `SKILL.md` - Description and instructions
- `examples/` - Example code and patterns
- `templates/` - Reusable templates
- `scripts/` - Helper scripts (if needed)

See individual skill folders for detailed instructions.
