# mCTAgents Advanced Enhancement Pack

This pack extends the existing mCTAgents blueprint and microservices strategy with a stronger, open-source-ready architecture.

## Main thesis

mCTAgents should become an **open-source social reasoning infrastructure** for AI-native products. It should not be only a multi-agent chatbot or a wrapper around an existing framework.

## Core decision

The project should be:

```text
Social Reasoning Protocol + Reasoning Engine + Studio UI + SDK + Benchmark Suite
```

not:

```text
Another multi-agent chatbot.
```
