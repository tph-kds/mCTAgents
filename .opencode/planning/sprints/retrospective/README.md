```markdown
**Attendees:** ...

- Item 1
- Item 2

## What to Improve

- Item 2

## Action Items
- [ ] Action 1 (Owner: ...)
- [ ] Action 2 (Owner: ...)

## Metrics
- Velocity: X points
- Bugs found: X
- Bugs fixed: X
- Test coverage: X%
```
