# ADR-008: Benchmark Suite Required Before v1.0

## Status
Accepted

## Context
We need to prove that multi-agent social reasoning improves answer quality.

## Decision
A benchmark suite comparing single-agent vs social-agent must be implemented and published before v1.0 release.

## Consequences
- Trust and quality proof for the project
- Prevents regression in reasoning quality
- Provides objective comparison metrics
- Adds development time before launch
