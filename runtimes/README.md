# mCTAgents Runtimes

Runtime adapters for integrating mCTAgents with popular agent frameworks.

## Available Runtimes

| Runtime | Status | Description |
|---------|--------|-------------|
| [LangGraph](langgraph/) | Beta | Adapter for LangChain's LangGraph framework |
| [Pydantic AI](pydantic-ai/) | Beta | Adapter for Pydantic AI framework |

## Usage

Each runtime adapter provides a way to use mCTAgents as a node in your existing agent workflow, or to use external agent tools within the mCTAgents protocol.
